# COMFORT 36

Vite + React + TypeScript. Лендинг, отдельная страница корзины и страница конфиденциальности. Каталог использует карточки из ВК Маркета. Видео в галерее загружается при открытии ролика.

```sh
npm ci
npm run dev
npm run build
```

Для обновления GitHub Pages запустите `npm run deploy`. Команда собирает сайт с базовым путём `/comfort36-landing/` и добавляет коммит в `gh-pages`. Ветки `backup-source-2026-11-23` и `backup-pages-2026-11-23` содержат предыдущие исходники и опубликованную сборку. Для отката содержимого Pages восстановите снимок из второй ветки в `gh-pages`.

## Заявки и отчёт

Сайт собирает черновик, который покупатель сам отправляет в сообщения ВК. При оформлении непосредственно в ВК Маркете заказ попадает в систему заказов ВК. Корзина сайта подготавливает обычное сообщение, а не заказ в интерфейсе ВК Маркета.

Для отчёта по полученным событиям ВК подготовлены `integrations/vk-relay.mjs` и `integrations/GoogleSheets.gs`. В отчёте дата по Москве, канал и разрешённые метки кампаний. Имена, телефоны, профили, сообщения и адреса остаются в ВК. Заказы ВК Маркета фиксируются отдельным каналом, без меток, поскольку событие ВК их не передаёт.

1. В целевой Google Таблице откройте **Расширения → Apps Script**. Вставьте `GoogleSheets.gs` и запустите `setupComfort36` один раз. Получится лист «Лиды» с фильтром и закреплённым заголовком.
2. В настройках проекта создайте Script Property `SHEETS_KEY` с длинным случайным секретом. Опубликуйте скрипт как веб-приложение от имени владельца с доступом для запросов без входа. Секрет проверяется при каждом POST. Скопируйте URL с окончанием `/exec`.
3. Разместите `vk-relay.mjs` под Node.js 24 за HTTPS на сервере в России. Укажите в окружении `VK_CALLBACK_SECRET`, `VK_CONFIRMATION_CODE`, `SHEETS_WEB_APP`, `SHEETS_KEY` и `QUEUE_PATH` на постоянном диске. `HOST` и `PORT` по умолчанию равны `127.0.0.1` и `8787`. Не включайте запись тел запросов в логи прокси.
4. В управлении сообществом настройте Callback API с адресом `https://ваш-домен/vk/callback` и секретом, включите `message_new` и `market_order_new`. Строку подтверждения ВК передайте в `VK_CONFIRMATION_CODE`.
5. В переменной `UTM_ALLOWLIST_JSON` задайте фактические значения кампаний, например `{"utm_source":["vk","yandex"],"utm_medium":["cpc"],"utm_campaign":["truck_mats"]}`. Значения вне списка не уходят в отчёт. Проверьте одной тестовой заявкой из ссылки с этими метками и одним тестовым заказом в ВК Маркете.

Для утверждения текстов согласия и политики у владельца сайта нужны реквизиты оператора и подтверждённые правила работы с заявками. На сайте опубликовано описание текущего сценария передачи черновика через ВК.
