# COMFORT 36 — лендинг грузового ателье

Креативный одностраничник для воронежского ателье **COMFORT 36** (3D-ковры, чехлы, накидки и оплётки в кабины тягачей).

**Демо:** https://goodrojh.github.io/comfort36-landing/

## Позиционирование

**УТП.** Грузовое ателье полного цикла: снимаем кабину 3D-сканером и шьём комплект по лекалам именно вашего тягача — за 5 дней и вдвое дешевле столичных ателье.

**Оффер.** 3D-ковры от 5 990 ₽ (в столичных ателье — от 12 990 ₽). Бесплатный замер и постановка модели в базу лекал. Комплект от трёх позиций — −15%. Срочный пошив за 2 дня. Гарантия посадки: сядет не идеально — перешьём за наш счёт.

**ЦА.** Водители-дальнобойщики 28–55 лет (кабина = второй дом), владельцы малых автопарков (2–15 машин, важна износостойкость и предпродажный вид), перегонщики и дилеры спецтехники.

## Что даёт лендинг сверх текущего сайта

- конфигуратор с расчётом цены онлайн и отправкой заявки в WhatsApp (сейчас заказ только через ВК);
- живые цены по каждой позиции вместо одной акционной;
- прозрачная таблица сравнения со столичными ателье и маркетплейсами;
- блок технологии (3D-скан → раскрой → пошив) с гарантией посадки;
- FAQ, снимающий основные возражения (педали, уход, сроки, «нет моей модели»).

## Стек

- Vite 5 + React 18 + TypeScript
- Tailwind CSS 3
- framer-motion — pull-up текста, посимвольное проявление по скроллу, каскад карточек
- lucide-react — иконки

Шрифты: **Manrope** (основной) и **Playfair Display Italic** (акцентная антиква). Взяты вместо Almarai / Instrument Serif из исходного брифа — те не поддерживают кириллицу.

## Медиа
