# Приём заявок COMFORT 36

1. Откройте существующую таблицу → Расширения → Apps Script. Замените код в редакторе содержимым GoogleSheets.gs и сохраните.
2. Выберите setupComfort36 и нажмите «Выполнить». Подтвердите разрешения на отправку почты и фоновую обработку. Настройки подключённого Telegram-бота сохраняются.
3. Откройте «Начать развертывание» → «Управление развертываниями». У существующего веб-приложения нажмите карандаш, выберите «Новая версия» и нажмите «Развернуть». Выполнение от имени владельца, доступ для всех. Адрес /exec остаётся прежним.
4. Форма открывает страницу благодарности после записи заявки. Лист «Заявки GitHub» используется для обоих адресов сайта. Фоновая обработка запускается каждую минуту. Столбцы Telegram и Почта показывают статус отправки.
5. Для смены почты добавьте LEAD_EMAIL_TO в настройках проекта → свойства скрипта. Изначально письма направляются на Halubets-1904@mail.ru.
