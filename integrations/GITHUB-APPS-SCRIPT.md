# GitHub Pages → почта, Google Таблица и Telegram

Почта подключена через FormSubmit. Для передачи тех же тестовых заявок в таблицу и Telegram используется Google Apps Script.

## 1. Telegram

1. Откройте [@BotFather](https://t.me/BotFather). Отправьте `/revoke`, выберите `@comfort36a_bot` и скопируйте новый токен. Прежний токен был опубликован в переписке.
2. Откройте [@comfort36a_bot](https://t.me/comfort36a_bot) и нажмите **Запустить**.
3. Придумайте код для подключения и отправьте его боту обычным сообщением. Например, используйте `C36-` и шесть своих цифр. Тот же код понадобится в Apps Script.

## 2. Таблица и Apps Script

1. Создайте пустую Google Таблицу. Откройте **Расширения → Apps Script**. Вставьте [код GoogleSheets.gs](https://raw.githubusercontent.com/goodrojh/comfort36-landing/main/integrations/GoogleSheets.gs) в `Code.gs` и сохраните.
2. Нажмите шестерёнку **Настройки проекта**. Внизу в разделе **Свойства скрипта** добавьте три строки.

   | Свойство | Значение |
   | --- | --- |
   | `TELEGRAM_BOT_TOKEN` | Новый токен из BotFather |
   | `TELEGRAM_CONNECT_CODE` | Код, который вы отправили боту |
   | `FORMSUBMIT_PREVIEW` | `true` |

3. В редакторе выберите `setupComfort36` и нажмите **Выполнить**. Если появится окно Google, выберите свой аккаунт и подтвердите запрошенный доступ к таблице и Telegram API. Появится лист **Заявки GitHub**.
4. Выберите `connectTelegram` и нажмите **Выполнить**. Бот пришлёт уведомление о подключении. Скрипт сам сохранит ID чата.
5. Запустите `testGitHubDelivery`. В таблице появится пробная строка с именем, телефоном, комментарием, составом и UTM. Эту же заявку пришлёт бот.
6. Нажмите **Развернуть → Новое развертывание → Веб-приложение**. Выберите выполнение **От моего имени** и доступ **Все**. После развёртывания скопируйте ссылку с окончанием `/exec`.

Пришлите ссылку `/exec` для подключения в сборке GitHub Pages. Токен и код подключения хранятся в свойствах Apps Script. После подключения сделайте одну пробную заявку на обычной странице GitHub и проверьте почту, строку в таблице и сообщение бота. Для теста используйте демонстрационные контакты. После завершения теста переключите `FORMSUBMIT_PREVIEW` на `false`.

[Документация Google о веб-приложениях](https://developers.google.com/apps-script/guides/web)
