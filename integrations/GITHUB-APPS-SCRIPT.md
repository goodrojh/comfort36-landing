# Приём заявок COMFORT 36

1. Откройте существующую таблицу → Расширения → Apps Script. Замените код в редакторе содержимым GoogleSheets.gs и сохраните.
2. Выберите setupComfort36 и нажмите «Выполнить». Подтвердите разрешения на отправку почты и фоновую обработку. Настройки подключённого Telegram-бота сохраняются.
3. Откройте «Начать развертывание» → «Управление развертываниями». У существующего веб-приложения нажмите карандаш, выберите «Новая версия» и нажмите «Развернуть». Выполнение от имени владельца, доступ для всех. Адрес /exec остаётся прежним.
4. Форма сразу открывает экран отправки. Подтверждение появляется после записи заявки. Оба адреса сайта пишут в «Лиды». При обновлении setupComfort36 переносит прежние заявки и статусы доставки по ID. Старый лист можно удалить после проверки переноса. После подтверждения сайт сразу запрашивает доставку уведомлений. Фоновая обработка раз в минуту подбирает оставшиеся заявки. Столбцы Telegram и Почта показывают статус отправки.
5. Для смены почты добавьте LEAD_EMAIL_TO в настройках проекта → свойства скрипта. Изначально письма направляются на cmfrt36@gmail.com.
